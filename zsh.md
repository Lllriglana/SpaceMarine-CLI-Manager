⚡️ **Краткая суть**
Работа с Java в терминале строится на двух базовых утилитах: компиляторе `javac` (переводит исходный код `.java` в байт-код `.class`) и виртуальной машине `java` (выполняет скомпилированный байт-код). Флаги определяют, куда сохранять и где искать файлы.

Ниже представлена структурированная шпаргалка в формате Markdown.

# ☕️ Полная хронологическая шпаргалка по терминалу Java для Лабораторной

Эта шпаргалка содержит базовые команды для сборки и запуска Java-проектов вручную через консоль — от компиляции исходников до настройки путей к классам.

## 1. Компиляция исходного кода (Утилита `javac`)
*Переводит человекочитаемый код из файлов `.java` в байт-код для виртуальной машины в файлы `.class`.*

* `javac src/Main.java` — Базовая компиляция. Создаст файл `Main.class` в той же папке, где лежит исходник (`src/`).
* `javac -d bin src/Main.java` — Компиляция со структурированием. Флаг `-d` (**directory**) указывает целевую папку. Создаст файл `Main.class` внутри директории `bin/`. Если папки нет, утилита создаст её сама.
* `javac -d bin src/models/*.java src/Main.java` — Компиляция нескольких файлов. Звёздочка `*` позволяет скомпилировать сразу все файлы `.java` в указанной директории.

## 2. Запуск скомпилированного байт-кода (Утилита `java`)
*Запускает виртуальную машину Java (JVM) и выполняет логику программы. Работает только с классами, а не с файлами.*

* `java Main` — Базовый запуск. Ищет файл `Main.class` строго в текущей папке терминала и запускает его.
* `java -cp bin Main` — Запуск из сторонней папки. Флаг `-cp` (или `--class-path`) задает путь, где JVM должна искать скомпилированные классы. В данном случае она зайдет в `bin/` и запустит там класс `Main`.
* **Важно:** При запуске указывается именно системное **имя класса**, а не путь к файлу. Писать расширение `.class` или путь вроде `bin/Main` в конце команды — синтаксическая ошибка.

## 3. Управление кодировкой (Решение проблем с кодами и кириллицей)
*Если в терминале вместо русского текста выводятся «кракозябры» или компилятор выдает ошибки на комментарии.*

* `javac -encoding UTF-8 -d bin src/Main.java` — Принудительно указывает компилятору считывать файлы в кодировке UTF-8.
* `java -Dfile.encoding=UTF-8 -cp bin Main` — Запуск JVM с передачей системного свойства `-D`, которое устанавливает кодировку вывода консоли в UTF-8.

## 4. Продвинутая сборка (Работа с зависимостями)
*Применяется, когда проект разрастается, использует внешние библиотеки или сложную структуру папок.*

* `javac -sourcepath src -d bin src/Main.java` — Флаг `-sourcepath` указывает утилите, где искать связанные файлы исходного кода, если `Main.java` ссылается на другие классы проекта.
* `java -cp bin:lib/postgres.jar Main` — Запуск проекта с подключением внешней библиотеки (например, JDBC-драйвера базы данных). В пути `-cp` можно перечислять папки и JAR-архивы через разделитель (двоеточие `:` в Linux/macOS или точка с запятой `;` в Windows).
* `java -Xmx512m -cp bin Main` — Флаг `-Xmx` ограничивает максимальный объем оперативной памяти (Heap memory), доступный виртуальной машине (в примере — до 512 Мегабайт).
