## 🛠 Интерактивные команды

Простые аргументы (примитивные типы, String, даты) вводятся в той же строке, что и имя команды. Составные типы (объекты) вводятся построчно.

* `help` — вывести справку по доступным командам.
* `info` — вывести информацию о коллекции (тип, дата инициализации, количество элементов и т.д.).
* `show` — вывести все элементы коллекции в строковом представлении.
* `add {element}` — добавить новый элемент в коллекцию.
* `update id {element}` — обновить значение элемента коллекции, id которого равен заданному.
* `remove_by_id id` — удалить элемент из коллекции по его id.
* `clear` — очистить коллекцию.
* `save` — сохранить коллекцию в файл.
* `execute_script file_name` — считать и исполнить скрипт из указанного файла (команды вводятся в том же формате, что и в интерактивном режиме).
* `exit` — завершить программу (без сохранения в файл).
* `add_if_min {element}` — добавить новый элемент в коллекцию, если его значение меньше, чем у наименьшего элемента этой коллекции.
* `shuffle` — перемешать элементы коллекции в случайном порядке.
* `history` — вывести последние 11 команд (без их аргументов).
* `count_less_than_weapon_type weaponType` — вывести количество элементов, значение поля weaponType которых меньше заданного.
* `filter_by_weapon_type weaponType` — вывести элементы, значение поля weaponType которых равно заданному.
* `print_unique_category` — вывести уникальные значения поля category всех элементов коллекции.

## ⌨️ Правила ввода данных

1. **Построчный UX:** Все составные типы данных вводятся строго по одному полю в строку. При вводе выводится текстовое приглашение с именем поля (например, *"Введите дату рождения:"*).
2. **Перечисления (Enum):** Перед вводом перечисления программа выводит список всех доступных констант. Пользователь вводит имя одной из констант.
3. **Валидация:** При неверном вводе (введена строка вместо числа, выход за границы диапазонов, неверное имя константы) выводится сообщение об ошибке и предлагается повторить ввод текущего поля.
4. **Пропуск значений (null):** Для ввода значения `null` используется пустая строка (нажатие Enter). Если поле не может быть `null`, система потребует корректный ввод.
5. **Автоматические поля:** Поля с пометкой *"Значение этого поля должно генерироваться автоматически"* (например, `id`, `creationDate`) не вводятся пользователем вручную.

## 📦 Структура данных (Модели)

### SpaceMarine
* `id` (**int**) — `> 0`, уникальное, генерируется автоматически.
* `name` (**String**) — `!= null`, строка не может быть пустой.
* `coordinates` (**Coordinates**) — `!= null`.
* `creationDate` (**java.time.LocalDate**) — `!= null`, генерируется автоматически.
* `health` (**Double**) — `!= null`, `> 0`.
* `category` (**AstartesCategory**) — может быть `null`.
* `weaponType` (**Weapon**) — может быть `null`.
* `meleeWeapon` (**MeleeWeapon**) — может быть `null`.
* `chapter` (**Chapter**) — `!= null`.

### Coordinates
* `x` (**Double**) — `> -540`, `!= null`.
* `y` (**Float**) — `!= null`.

### Chapter
* `name` (**String**) — `!= null`, строка не может быть пустой.
* `marinesCount` (**int**) — `> 0`, максимальное значение: `1000`.

### Перечисления (Enums)
* **AstartesCategory**: `SCOUT`, `INCEPTOR`, `TERMINATOR`, `LIBRARIAN`, `CHAPLAIN`.
* **Weapon**: `MELTAGUN`, `COMBI_FLAMER`, `GRENADE_LAUNCHER`.
* **MeleeWeapon**: `CHAIN_AXE`, `LIGHTING_CLAW`, `POWER_BLADE`, `POWER_FIST`.
